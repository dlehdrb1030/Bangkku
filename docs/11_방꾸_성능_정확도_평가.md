### 1.4 렌더링 설정 비교 (Windows VR에서 시험 후 결정)

| 설정 | 결과 | 결정 |
|---|---|---|
| Render Mode: Single Pass Instanced | 3DGS가 **한쪽 눈에만** 보임 | 쓰지 않음 |
| Render Mode: **Multi-pass** | 양쪽 눈 정상, 의자 1개·가구 10개 모두 72fps | **사용** (11-15, PR #53) |
| MSAA 4x | 고정설비 깜빡임은 줄지만 **3DGS 가구가 깨지고 자글자글함** | 쓰지 않음 (11-16, PR #63) |
| **MSAA 끔** | 3DGS 정상. 고정설비 깜빡임은 모델 코드 수정(겹친 면 제거, 문짝 틈 3 → 6mm)으로 해결 | **사용** |
| 헤드셋 렌더 해상도 1.0 → **1.3배** | 돌 때 벽 모서리·무늬 자글거림이 줄어듦, 프레임·GPU 여유 변화 없음 | **사용** (11-16, PR #70). 멀리 있는 얇은 창틀·문틀의 일렁임은 남음 (MSAA 없이 생기는 한계) |
| ASW Auto | 72fps를 못 지키면 36fps로 고정 → 실제 성능이 가려짐 | 측정할 때만 Disabled |

### 1.5 지연시간 해석

| 구간 | 시간 | 누가 결정하나 |
|---|---|---|
| 머리 위치 읽기 → 앱 렌더링 → Timewarp에 넘김 | 약 8~10ms (App Tracking − Timewarp) | **우리 앱** (72Hz 한 프레임 13.9ms 안) |
| Timewarp → 화면 넘김(Flip) | 약 9ms | Meta 런타임 |
| Flip → 헤드셋 화면 표시 | 약 26ms | **Link**: 영상 압축 → USB 전송 → 헤드셋에서 풀기 → 표시 |

- 45ms 중 약 35ms는 PC VR(Link) 구조에서 생기는 시간이라 앱으로는 줄일 수 없다. 앱 몫은 약 10ms로 한 프레임 안이다.
- 헤드셋 단독 실행(APK)은 Link 구간이 없어 지연이 짧지만, 3DGS를 지원하지 않아(전체개발계획 2장 제외 범위) 박스 가구만 쓸 수 있다.

## 2. 정확도 평가표

판정(겹침·간격)은 **판정 박스**(가구 메뉴·카탈로그의 W·D·H)로만 한다 (전체개발계획 1장 "박스는 판정, 3DGS는 외관"). 그래서 정확도를 세 가지로 나눠 본다.

1. 방: 평면도 JSON으로 만든 방이 도면 치수와 맞는가
2. 가구 외관: 3DGS 가구 크기가 판정 박스와 얼마나 맞는가
3. 판정: 배치·간격·겹침을 몇 mm 단위로 판단하는가

### 2.2 가구 외관 (3DGS) ↔ 판정 박스

- 판정 박스: 가구점 표기 치수(`drawing`, 판정 여유 30mm). `standbyme_01`만 스캔 기반 추정(`estimated`, 100mm).
- 외관 크기: 스플랫 중심 좌표의 축별 범위(양끝 1%씩 버림, `SplatFitter`) × 프리팹 `Visual`의 균일 배율.
- 보정 오차(`fitError`): 세 축 중 외관과 판정 박스 차이가 가장 큰 축의 비율. 균일 배율이라 세 축을 동시에 딱 맞출 수는 없다.

| 가구 | 판정 박스 W×D×H (mm) | 3DGS 외관 W×D×H (mm) | 차이 W / D / H (mm) | 보정 오차 |
|---|---|---|---|---|
| 침대 `bed_01` | 1,700×2,100×1,110 | 1,666×2,040×1,072 | −34 / −60 / −38 | **3.4%** |
| 높은 원형 탁상 `round_table_02` | 1,050×1,050×740 | 979×978×694 | −71 / −72 / −46 | 6.8% |
| 3인용 소파 `sofa_01` (MCMC) | 2,320×930×910 | 2,148×892×842 | −172 / −38 / −68 | 7.4% |
| 일체형 의자 `shell_chair_01` | 460×550×940 | 427×507×877 | −33 / −43 / −63 | 7.8% |
| 산스베리 책상 `desk_01` | 1,100×670×730 | 1,077×651×672 | −23 / −19 / −58 | 8.0% |
| 낮은 원형 탁상 `round_table_01` | 900×900×480 | 834×840×434 | −66 / −60 / −46 | 9.5% |
| 토네브로 보조테이블 `beige_stool_01` | 460×460×605 | 434×431×546 | −26 / −29 / −59 | 9.7% |
| 사무용 의자 `office_chair_01` (MCMC) | 640×640×950 | 605×596×836 | −35 / −44 / −114 | 12.0% |
| 팔걸이 의자 `armchair_01` | 770×880×750 | 717×772×739 | −53 / −108 / −11 | 12.3% |
| 스탠바이미 `standbyme_01` (추정 치수) | 914×493×1,489 | 906×437×1,452 | −8 / −56 / −37 | (보정 안 함) |

- 표기 치수가 있는 9종: 보정 오차 **평균 8.5%, 중앙값 8.0%**, 10% 이하 7종.
- MCMC 교체 효과: 사무용 의자 15.6% → **12.0%** (높이 차이 −149 → −114mm), 소파 7.5% → 7.4%. 교체 전 9종 평균은 8.9%였다.
- **모든 축에서 외관이 판정 박스보다 작다** (차이가 모두 음수). 판정 박스가 3DGS 외관을 감싸므로 겹침·간격 판정은 실제보다 보수적(안전한 쪽)이다.
- 외관이 작게 나오는 이유: 범위를 잴 때 양끝 1%를 버리고, 스캔에서 가늘거나 반사되는 부분(의자 다리·바퀴, 소파 팔걸이 끝 등)이 덜 찍힌다. 사무용 의자 높이(−114mm)·팔걸이 의자 깊이(−108mm)가 그 예이다.
- 보정 오차 10% 초과 2종(`office_chair_01`, `armchair_01`)은 재촬영하지 않기로 했다 (11-16 결정, 사무용 의자는 같은 촬영본을 MCMC로 다시 만들어 15.6 → 12.0%). 판정은 박스로 하므로 배치 판단에는 영향이 없고, 외관이 박스보다 조금 작게 보인다.

### 2.3 배치·판정 정밀도

| 항목 | 값 | 근거 |
|---|---|---|
| 좌표·치수 단위 | 1mm (JSON 정수 mm, Unity 1 unit = 1m) | 전체개발계획 5장, `Units.MM_TO_M` |
| 위치 격자 스냅 | 10mm | `PositionSnap.GridMm` |
| 벽 스냅 | 벽 밖 30mm 이내 → 벽 면에 붙임 (틈 0mm), 벽 안 150mm 이내 → 벽 면으로 되돌림 | `PositionSnap` (PR #70) |
| 회전 | Y축만, 90° 스냅, 미세 15° | `RotationSnap` |
| 맞닿음 허용 | 1mm (벽·가구에 딱 붙인 가구는 겹침이 아님) | `PlacementValidator.ContactToleranceMm` |
| 판정 주기 | 0.1초 | `PlacementValidator` |
| 판정 여유 (치수 신뢰도) | 실측 10mm / **도면 30mm** / 추정 100mm, 좁음 기준 최소 50mm | 전체개발계획 5장, `PlacementValidator.MinTightGapMm`, `TightRule` |
| 배치 저장 | 위치 정수 mm, 회전 0.01° 단위 | `LayoutSaver` (`layout.json`) |

- 판정 박스·방 모두 치수 오차 0mm로 만들어지므로, 판정 오차는 **입력 치수의 오차**(가구점 표기 ±30mm, 도면 그림에서 잰 벽 ±100mm)가 대부분이다. 판정은 이 여유값을 더해 "좁음(노랑)"으로 미리 알린다.

## 3. 발표용 요약

- **성능**: RTX 5080 + Quest 2(Link)에서 3DGS 가구 10개(스플랫 약 70만 개) + 판정 표시 상태로 **72fps 유지, GPU 여유 63~65%**. (소파·의자 MCMC 교체 전 측정. 교체 후 약 92만 개로 재측정 예정)
- **지연**: 45ms 중 앱 몫은 약 10ms(한 프레임 안), 나머지 약 35ms는 Link 영상 전송 구간.
- **방 정확도**: 평면도 2개, 도면 치수 18개 **오차 0mm**.
- **가구 외관 정확도**: 3DGS 외관과 판정 박스 차이 평균 8.5%(중앙값 8.0%). 외관이 모든 축에서 박스보다 작아 판정은 보수적.
- **판정 정밀도**: 1mm 단위 좌표, 10mm 격자, 벽 밀착 0mm, 신뢰도별 여유 10 / 30 / 100mm.
