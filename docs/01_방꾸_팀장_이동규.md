## 2. 맥북 개발 방식
- 평일은 맥에서 **데스크톱 모드 + XR Device Simulator(또는 Meta XR Simulator)** 로 개발·테스트
- 실제 헤드셋 감각 확인이 필요하면 **Quest 단독 APK**로 빌드해서 Meta Quest Developer Hub로 설치 (박스·메쉬 가구까지만)
- Unity Hub에서 **Android Build Support** 모듈 설치, Quest 개발자 모드 활성화
- **3DGS 포함 VR 확인과 성능 측정, 최종 빌드는 금요일에 Windows VR PC에서**
- 맥 에디터는 Metal, Windows는 DX12/Vulkan → 금요일에 Windows에서 화면이 같은지 꼭 확인

## 4. 구현 메모

### 벽 생성 (`WallMeshBuilder`)
```
입력: start, end(mm), thickness, ceilingHeight, 이 벽의 openings
1. dir = normalize(end - start), L = |end - start|
2. 벽을 양 끝으로 thickness/2씩 연장 (모서리 빈틈 방지)
3. openings를 offset 순 정렬
4. cursor = 0
   각 개구부 o:
     [cursor, o.offset] → 전체 높이 조각
     [o.offset, o.offset + o.width] → 아래(0~sill) + 위(head~천장) 조각, 창이면 유리판(두께 10mm)
     cursor = o.offset + o.width
   [cursor, L] → 전체 높이 조각
5. 조각 = 큐브 (길이 × 높이 × 두께), 중심·회전 계산, BoxCollider, Layer = Wall
```

### 겹침·간격 (`PlacementValidator`)
```
overlaps = Physics.OverlapBox(center, halfSize - 0.001, rotation, Wall|Furniture|Fixture) - 자기 자신
minGap  = 박스 4측면 중앙에서 바깥으로 수평 Raycast(최대 1m) 중 최솟값
margin  = max(가구 신뢰도 여유값, 맞닿은 벽 신뢰도 여유값)
state   = overlaps 있음 → Overlap
          minGap < max(margin, 0.05m) → Tight
          그 외 → Free
```
- 3DGS 색은 바꾸지 않고 **윤곽선·반투명 박스**로 상태를 표시

### 데스크톱 모드 (`DesktopController`)
- 좌클릭: 가구 선택 (Layer = Furniture 레이캐스트)
- 드래그: 바닥 평면(y=0)과 마우스 레이 교점으로 이동, 스냅 동일 적용
- Q/E: 90° 회전, Shift+Q/E: 15°
- 우클릭 드래그 + WASD: 카메라 이동, 마우스 휠: 줌
- VR 장비가 없으면 자동으로 데스크톱 모드로 시작 (XR 초기화 실패 감지)

## 5. Claude Code에 맡기기 좋은 작업 (예시 프롬프트)
작업 요청 시 항상 `00_방꾸_전체개발계획.md`와 이 문서를 함께 참조하게 합니다.

- "전체개발계획 7.1의 floorplan.json 형식에 맞는 `FloorPlanData.cs`와 Newtonsoft 기반 `FloorPlanLoader.cs`를 `Bangkku.FloorPlan` 네임스페이스로 만들어줘. 단위 변환은 `Units.MM_TO_M`만 사용."
- "팀장 가이드 4장의 벽 분할 알고리즘으로 `WallMeshBuilder.cs`를 만들어줘. 각 조각은 큐브 + BoxCollider + Layer Wall."
- "오목 다각형을 지원하는 귀 자르기 삼각분할 `PolygonMesh.cs`를 만들어줘. 입력은 mm 좌표 리스트, 출력은 바닥 메쉬."
- "전체개발계획 8.2 API를 지키면서 `PlacementValidator.cs`를 만들어줘."
- 씬·프리팹 구성은 에디터에서 직접 하고, Claude Code에는 스크립트와 JSON만 맡깁니다.
