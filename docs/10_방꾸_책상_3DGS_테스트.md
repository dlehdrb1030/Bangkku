# 방꾸 책상 3DGS 테스트 — desk_01

[PR #51](https://github.com/dlehdrb1030/Bangkku/pull/51) · 작업 브랜치 `feature/hj-splat-first` · 대상 브랜치 `dev`

## Unity에서 확인하기

1. Unity **6000.3.27f2**로 방꾸 프로젝트를 엽니다. 이 PC에서는 Unity Hub의 **Installs → Locate**에서 `D:\가상현실\Unity-6000.3.27f2\Editor\Unity.exe`를 선택해 에디터를 등록할 수 있습니다. **Projects → Add → Add project from disk**에서 `D:\가상현실\Bangkku-splat-first`를 추가합니다.
2. Unity의 **Project** 창에서 [Test_Splat.unity](../Assets/_Project/Scenes/Test_Splat.unity)를 엽니다. 경로는 `Assets/_Project/Scenes/Test_Splat.unity`입니다.
3. **Play**를 누르고 **Game** 탭을 클릭합니다. 원룸의 주방 근처에 검은 책상이 있습니다. 휠로 확대하고, **우클릭 + 마우스**로 시점을 돌리거나 **우클릭 + WASD**로 이동합니다.
4. 책상을 **좌클릭**해 선택하고 드래그로 옮겨 봅니다. **Q/E**는 90° 회전, **Shift + Q/E**는 15° 회전입니다. Hierarchy에서 `desk_01`을 펼치면 `Visual/DeskSplat`과 판정용 `Collider`를 확인할 수 있습니다.

팀원이 새로 받을 때는 Git LFS를 설치한 뒤 다음 명령으로 테스트 브랜치를 받습니다.

```bash
git clone --branch feature/hj-splat-first https://github.com/dlehdrb1030/Bangkku.git
git -C Bangkku lfs pull
```

책상이 표시되지 않으면 **Console**에서 PLY 로드 오류를 확인합니다. Windows 에디터의 그래픽 API가 **DX12**인지, PC Renderer에 **Gaussian Splat URP Feature**가 켜져 있는지, PLY가 Git LFS에서 내려받아졌는지 확인합니다.

## 치수와 확인 결과

- **제품 라벨** 기준 길이 × 폭 × 높이는 **1100 × 670 × 730 mm**입니다. 테스트 씬의 판정 박스는 Unity X/Y/Z 순서로 **1.10 / 0.73 / 0.67 m**이며, 치수 신뢰도는 상품 표기에 해당하는 `Drawing`입니다.
- `DeskSplat`에서 원본 −Y가 위를 향하도록 Z축 180° 회전 후, 긴 변이 X축에 놓이도록 Y축 90° 회전했습니다. 균일 스케일은 **1.2184**입니다. 상·하위 1%를 제외한 스플랫 중심 좌표 기준으로 보정 후 높이 추정치는 **약 686 mm**이고, 제품 라벨과의 차이는 **약 6.1%**입니다.
- **Windows, Unity 6000.3.27f2, DX12**의 Play 모드에서 스플랫 로딩·화면 출력·판정 박스 크기를 확인했습니다. 헤드셋 없이 실행한 로그에는 OpenXR 디스플레이 초기화 실패가 기록됐습니다.
- **PC VR 확인**은 헤드셋을 연결한 팀장 환경에서 진행합니다. 양안 표시와 FPS는 [VR 테스트 가이드 2-B](07_방꾸_VR_테스트.md)에 따라 확인합니다.
