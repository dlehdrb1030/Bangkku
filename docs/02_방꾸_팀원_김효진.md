## 4. 구현 메모

### 촬영 요령
- 가구를 벽에서 30cm 이상 떼고, 주변 **한 바퀴 + 위에서 한 바퀴**, 천천히
- 낮, 커튼으로 직사광선 차단, **고른 간접광**
- 처음엔 **무늬 있는 천 소파, 나무 의자** (흰색·광택·유리 가구는 실패하기 쉬움)
- 바닥에 무늬 있는 매트를 깔면 포즈 추정이 안정적
- 원본 영상과 원본 `.ply`는 드라이브 `방꾸/raw/`에 보관

### 정리 순서 (SuperSplat)
1. 바닥·벽·배경 삭제
2. 공중의 floater 삭제
3. 가구 바닥을 Y=0, 중심을 원점으로
4. 정면이 +Z를 보도록 회전
5. `.ply` 내보내기, 파일명에 버전 (`sofa_01_v2.ply`)

### 크기 보정 (`SplatFitter`)
```
1. 가우시안 위치들의 바운딩 박스 b (각 축 상·하위 1% 제외 → floater 영향 감소)
2. 줄자 실측 s (catalog의 size)
3. 균일 배율 k = median(s.w/b.w, s.d/b.d, s.h/b.h)    ← 축별 배율 금지
4. 오차율 e = max_i |s_i - b_i * k| / s_i
5. Visual 스케일 = k, catalog에 splatMeasuredSize, fitError 기록
6. e > 0.05 → 콘솔 경고 (재촬영 후보)
```

### `FurnitureFactory`
```
CatalogLoader로 catalog.json 로드
Create(itemId, position(mm), rotationY):
  item = catalog[itemId]
  source == scan/mesh → item.prefab 인스턴스화
  source == box       → FurnitureItem_Base 인스턴스 + Visual에 큐브(color)
  Collider.size = size(m), center.y = h/2
  FurnitureItem.Init(item)
  위치 = position * MM_TO_M, y = 0
```
- 판정·상태 표시 코드는 팀장 소유. 나는 `Init()`만 호출

### 성능 최적화 순서
1. **색상 정보 단순화 (SH 차수 최소화)** → 회전 시 색 왜곡도 해결
2. SuperSplat에서 불필요한 가우시안 추가 삭제
3. 플러그인 품질·압축 설정 낮추기
4. 가구당 가우시안 상한 (시작 기준 20만 개, 측정 후 조정)
5. 그래도 부족하면 해당 가구를 메쉬로 대체

## 5. Claude Code에 맡기기 좋은 작업 (예시 프롬프트)
작업 요청 시 항상 `00_방꾸_전체개발계획.md`와 이 문서를 함께 참조하게 합니다.

- "전체개발계획 7.2 형식으로 `CatalogData.cs`에 맞는 `CatalogLoader.cs`를 `Bangkku.Furniture` 네임스페이스로 만들어줘. Newtonsoft 사용."
- "팀원 가이드 4장의 알고리즘으로 `SplatFitter.cs`를 만들어줘. 가우시안 위치 배열을 입력으로 받아 균일 배율과 오차율을 반환."
- "팀원 가이드 4장의 `FurnitureFactory` 설계대로 만들어줘. `FurnitureItem.Init()`만 호출하고 판정 코드는 건드리지 마."
- "`PerfRecorder.cs`: 지정 시간 동안 fps 평균·최저와 씬의 총 가우시안 수를 CSV로 저장."
- 플러그인 내부 코드는 수정하지 않습니다. 버전 업데이트도 팀장과 합의 후.

## 6. 협업 체크
- `.ply`, `.glb` 등은 **Git LFS**로만 커밋. 크면 드라이브 `방꾸/splats/`
- 가구 프리팹은 반드시 **`FurnitureItem_Base`의 Prefab Variant**로
- 넘기기 전 확인: 원점 = 바닥 중앙, 정면 = +Z, Collider 크기 = `size`, Layer = Furniture
- `Main_VR.unity`, `Core/`, `Data/` 는 직접 수정하지 않음. 필요하면 팀장에게 요청

## 7. 막혔을 때 대안

| 상황 | 대안 |
|---|---|
| 플러그인이 PC VR에서 안 보임 (1주차) | Polycam 메쉬(.glb)로 전환, 3DGS는 데스크톱 시연만 |
| 촬영 결과가 계속 깨짐 | 무늬 있는 가구로 변경, 조명 재조정, 매트 깔기 |

| 72fps 안 나옴 | 최적화 순서대로, 최후엔 메쉬 대체 |
